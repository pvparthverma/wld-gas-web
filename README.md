# Weird Little Dude Gets a Sandwich (web)

## Controls

WASD to move, Space/K to dash, H to hit, and U to skip level.
Stopwatch embedded into website to let you keep track of time

## Description

This game was made for an AP CSA final project, however I thought I'd make a web port so anyone can play without installing Java.
This was relatively easy to do, as there's a lot of documentation for libGDX and html5 game ports.
I decided to compile this using TeaVM, and embedded the game within an iframe

## AI

AI usage was low, just Claude for debugging physics (X-axis movement was awful when building for web, but desktop build would be fine), and the
Copilot auto-code completion.
